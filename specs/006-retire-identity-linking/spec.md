# 规格：退役身份关联与旧快照转换

日期：2026-10-22。状态：已完成本地验收。规则来源：[项目章程](../../AGENTS.md)。

## 问题与目标

身份别名关联只更新查询编号，不更新已有记忆归属，可能使旧数据无法访问。当前服务已经按
namespace 隔离 Memory，控制台没有关联入口。取消这项额外能力，统一按原始 user_id 读写；
同时退役依赖解析器且已决定停止维护的 pickle 转换工具。

## 行为契约

- 删除 Memory.link_identity、Memory.resolver、IdentityResolver 及 Ingestor 的 resolver 参数。
- user_id 保留默认值 default；使用传入的原始字符串，不归一化、不关联不同编号、不合并空间。
- 事实、原文、摘要、画像、工作记忆、历史、审计与删除使用一致的归属条件。
- 保留姓名、昵称、第一人称共指及图谱实体别名；这些不是用户编号关联。
- 新快照不保存 resolver_parent，JSONL 集合与 schema_version=1 不变。
- 加载器只允许缺失、空字典或字符串到自身的旧映射。非法字段和真实关联映射在改动运行时
  store 前抛出 StoreFormatError，不自动迁移、不静默忽略关联。错误不包含用户编号。
- 删除旧 pickle 模块、发行命令、专用测试与当前支持说明。普通加载仍拒绝文件而不执行 pickle。
- 不读取、转换、删除真实旧文件，不修改 API key、空间授权、路径和锁协议。

## 验收

不同 user_id 在同一个 Memory 内隔离，重启后双时间、来源和替代链保持；姓名/昵称重启后
仍有效。audit 与 clear_slot 的集合一致，计数变化拒绝删除，保护手写事实和历史。
新构建包不含退役模块/命令。完整 pytest、zero-setup、release、包构建通过；真实小切片
记录检索等价性、tokens 和延迟，缺数据时如实记录未完成，不作准确率或性能提升声明。
