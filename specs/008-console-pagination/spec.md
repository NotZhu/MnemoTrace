# 控制台分页与结论筛选规格

目标：四个列表完整遍历同一匹配集合；缓存只由 Infinite Query 提交，浏览状态与统计使用同一评估时刻。

1. 服务端在分页前组合类型、状态、搜索、分类和敏感范围。outcome_kind 限定 decision/finding/lesson/open_question。
2. 事实、时间线、结论、原始对话固定页大小为 40/60/60/20；按服务端 next_offset 前进，按 ID 合并并保持组件身份。事实/原文显式单页上限为 500/200，未传 limit 保留全文语义；同时间按 ID 倒序。
3. 首次请求返回 data_revision 与 evaluated_at（Unix 秒）；后续页成对传 expected_revision 与 evaluated_at。缺一项、负数或非有限时间值拒绝。版本变化返回 409 memory_revision_changed，不返回可追加记录。
4. 服务在读取作用域内捕获一次评估时刻；过滤、行 status、facts_live/facts_superseded/facts_outcomes 均按该时刻判定。空间统计范围不变。自然时间流逝不改变当前批次，重载使用新时刻。
5. data_revision 只跟踪标准持久化写入提交，empty 表示无提交；裸 Memory 未保存修改不受保护，不增加内存版本或历史快照。
6. 同一查询只有 Infinite Query 管理请求与提交。显式 refetch(cancelRefetch=true) 和标准写后失效从第一页重建已加载页数，全部成功后统一替换；新末页提前结束。不得使用 pages=1、手动 setQueryData、独立重载 mutation 或时间戳仲裁。
7. 所有写后失效先显式取消同一登录周期内的目标查询，等待取消完成后再失效；无缓存首屏也必须重新读取。取消等待后若账号或登录周期改变，不得影响新周期。新增、编辑、删除、导入/关闭会话、冲突处理和策略更新共用该入口；不增加第二缓存写入者。
8. 查询接入 AbortSignal；即使传输忽略取消，旧请求也不能提交。条件/账号/登录周期隔离；普通失败下一页仅重试该页。整批刷新失败保留所有旧页与草稿；版本冲突停止追加，由用户重载，不自动追赶。
9. 同范围搜索可保留占位展示，但不能冒充新计数或空态，期间禁用分页；顶部待解决问题独立取 live open_question，沿用搜索、最多 8 条。
10. 同步 HTTP 文档、控制台和 TypeScript SDK 参数/响应/枚举及 409 契约；不保留未发布旧契约兼容分支。

边界：不改检索算法、存储格式、时间线人物/日期筛选与替换链，不声明准确率收益，不提交、推送、合并或部署。只用合成数据，现有手工服务保持运行。
