# 控制台脚本权限与接入凭据

## 用户场景与验收

- HTML 头部同步加载同源主题脚本，首次绘制前恢复主题；生产 script-src 仅 self，样式策略不变。
- 网页生成的 PowerShell/Bash 命令不接收 Key，安装成功后隐藏输入；回显不可禁用、取消或输入无效时不写配置。
- 远程安装不默认使用 me；显式 Key、私有文件、隐藏输入互斥，保留环境变量入口，本地 namespace 零配置。
- 安装把凭据写入用户私有目录，以随机名称原子提交；配置、验证命令仅引用绝对文件路径。重复安装相同身份复用文件，更换身份先安全写入再更新引用。
- POSIX 目录 0700、文件 0600；Windows DACL 仅当前用户与 SYSTEM。拒绝链接、非普通文件、不安全权限；错误不回退身份。
- 所有预览、诊断、错误均不包含真实 Key；dry-run 无持久化副作用，备份先受保护后写入；卸载不删除凭据。
- 原浏览器只清除两个已知凭据项，保留主题和偏好；不可访问时留待验收，不建立历史登录兼容逻辑。

## 边界

不修改记忆算法、服务端租户语义或公开成绩，不引入依赖。私有凭据文件是权限保护的明文，不是加密存储。
显式 --api-key 仍可直接调用，但不出现在生成配置中；旧配置不自动迁移，用户显式重新安装。
验收记录使用合成 Key，实际浏览器只记录键存在与否，不读取内容。

## 凭据路径与配置读取约定

- 凭据路径统一展开用户目录，并以调用时工作目录转为绝对路径；不消解链接。读取、安装及所有客户端片段共用规则；占位符不变，生成阶段不写文件。
- setup 与 doctor 通过独立模块读取配置。Python 3.11+ 使用 tomllib；Python 3.10 的标准库读取器仅处理 command 字符串及 args 字符串数组，支持多行数组、单双引号、字符串内 #、行尾注释及尾逗号。
- 引用复用是可选优化；不支持的表达形式跳过复用，doctor 明确诊断。已识别引用的缺失、权限、链接与内容错误仍阻止写入。常见多行配置重复安装相同凭据不增加文件。
- 模拟缺少 tomllib 的测试不等同原生 Python 3.10 验收。本次仅修复这两处边界，不改前端、算法与公开数字；不暂存、不提交、不推送。

## 诊断报告脱敏约定

- 合法 Key 可与字段名或状态重名；脱敏不得改变报告字段名、成功标志、客户端枚举、汇总计数或检查项固定名称与状态。
- 共享脱敏保留字典键与非文本值；doctor 按报告结构仅处理路径、地址、详情、展示命令和 data 字符串内容，并返回副本，不修改原始探针。
- 文本与 JSON 输出共用报告；doctor 和 setup 的成功判断始终来自原始探针结果。不得禁止特定 Key、捕获 KeyError 或改变退出判断来规避问题。

## 配置生成与文本脱敏边界

- 纯生成函数不接收 Key，仅使用接入参数及凭据文件引用；本地 namespace 与远程脱敏 Key 分开传递，CLI 不变，不保留无用 Python 参数的兼容别名。
- 四类 setup 渲染不对成品全文脱敏。固定代码、工具名、配置键及功能参数保留精确值，按目标语法转义；与 Key 偶然同字不视为凭据回显。
- 自由诊断文本在插入模板前脱敏，嵌入报告通过 doctor 的结构化边界处理。配置/策略块使用当前生成器产物；不解析或迁移旧版含 Key 的块，不修改输入对象。
- 通过解析成品与实际安装结果对照、跨工作目录真实 stdio 接入验收；继续不暂存、不提交、不推送。

## TOML 字符串编码约定

- command 与每个 args 元素使用统一 TOML 双引号基础字符串编码，保留合法 Unicode，正确转义引号、反斜杠、ASCII 控制字符与 DEL；不使用 JSON 代理项对表示非 BMP 字符。
- 孤立代理项以固定、不含输入内容的 CredentialError 拒绝，不覆盖已有配置；编码函数不承担通用 TOML 写入或配置迁移。
- 成品以 UTF-8 字节交给真实 TOML 解析器验收，解析后参数精确还原；覆盖 Unicode 用户目录/凭据路径、重复安装、读取与真实 stdio。JSON/shell 编码和公共接口不变。

## Windows 文件所有者约定

- 新建私有目录、临时凭据及配置备份必须显式设置当前用户为所有者，同时施加仅当前用户与 SYSTEM 的受保护 DACL；不依赖创建进程的默认所有者。
- 只读校验仍拒绝当前用户/SYSTEM 之外的所有者，不放宽到 Administrators，不修改现有不安全凭据。所有者设置失败时保持零凭据字节写入和原目标不变。
- 回归覆盖管理员组默认所有者、只读拒绝、设置失败与重复安装；本机模拟默认所有者和远程原生 Windows 验收分别记录。
