# 查询结果复用范围

本规格定义事实查询在筛选条件变化时的旧响应复用边界，以及加载、失败和重试期间的展示行为。

## 用户场景与验收

- 隐藏敏感内容时，立即停止展示旧范围响应；有当前条件缓存则使用，否则仅列表区域加载，工具栏保持可用。
- 账号、kind、敏感范围、分类、状态和分页偏移变化均不能借用旧响应。仅搜索词和请求条数变化可复用，并显示更新状态。
- include_sensitive 未传等价于 false；空分类等价于未传。未来筛选字段默认参与复用比较。
- 无当前数据时，计数不冒充零；分类仅保留“全部”和当前值；失败可重试；占位空结果不宣称新查询无匹配；占位期间不能使用旧分页继续加载。
- 等待、失败、重试、连续切换、迟到响应及账号切换均遵守上述边界。

## 边界与澄清

筛选范围变化且没有当前条件缓存时，列表显示加载状态。实现范围为共享查询与事实列表，不包含独立冲突卡片、来源、画像、后端或结论页的分页筛选。
公共 API、数据结构、默认服务端过滤、登录周期隔离不变；无新依赖、无存储迁移、无质量 benchmark 声明。
