# 实施计划

1. 保存基准 commit、完整工作树 diff，构建旧控制台并启动隔离服务，浏览器复现设置草稿丢失。
2. 添加 Layout 与局部状态失败回归，解除全局错误与卸载的绑定，恢复局部 ErrorState 可见性。
3. 逐项补充刷新失败/dirty 草稿/来源/未知状态回归，保留编辑区域与其查询范围；结论分组调整不改变已有编辑行的身份。
4. 添加导航回归并改为 Router Link，保持内存登录及 basename。
5. 完整回归与生产构建后，在相同真实服务完成浏览器验收及截图；开发代理补验导航。
6. 整理证据，更新架构模块与台账，检查受管和未跟踪文件的 diff；补丁使用零上下文格式并检查可恢复性，关闭自行启动的进程和浏览器空间。

## 约束与验证边界

复用 React Query、现有 ErrorState 和 Router，不引入依赖或生产测试入口。
测试边界由批准计划确定：页面行为、真实 QueryClient/API/认证 store，以及浏览器真实 DOM。
合成账号及数据位于独立目录，网络注入仅包裹目标 GET，其他请求透传真实后端。
完整前端测试、类型检查及构建为完成门禁；实际推送前运行 pytest。
