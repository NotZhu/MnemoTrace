# 控制台查询错误与导航生命周期

范围：查询错误导致的草稿丢失，以及设置页内部导航导致的重新登录；包含真实服务浏览器截图验收。

## 行为契约

- 普通查询错误不卸载路由页面；错误由依赖该数据的区域呈现，全局条仅告警与重试。
- 设置、会话输入、关注设置、结论编辑、体检编辑在辅助失败和主查询后台刷新失败时保留组件、草稿和选择。
- 当前查询无数据时显示加载/错误；已有数据刷新失败时保留内容并标明更新失败，dirty 输入不被恢复响应覆盖。
- 结论行按事实 ID 保持编辑组件身份；恢复结果新增、拆分或合并连续会话分组时，已有行的编辑状态和草稿不变。
- 来源错误与成功空结果分开；未知接入状态不显示为零或空结果。
- 账号/登录周期变更仍重建页面并清理私有缓存、错误和草稿，旧请求不影响新周期；当前 401 仍退出。
- 内部导航使用 Router 并遵守 basename，凭证和草稿不新增持久化。

## 验收

目标回归先失败再修复，加入既有 CI 入口，运行完整前端测试与构建。
启动独立数据目录、双合成账号、无模型的真实 FastAPI，托管生产控制台。
浏览器仅对指定读取实施网络故障注入；验证失败、重试、恢复、主查询刷新、账号隔离及内部导航。
设置/会话输入/事实编辑各保存失败与恢复截图，至少六张，并逐张检查。
记录原始输出、实际代码 diff、复现脚本、验证边界；全部通过后才更新台账为本地已修复。
证据补丁须可还原当前源码；格式检查同时覆盖已跟踪改动和未跟踪的待提交文件。

## 非目标

不改变 HTTP/API/schema、存储、算法或 benchmark 数字；不实现跨路由/刷新草稿恢复，不接触真实数据。
