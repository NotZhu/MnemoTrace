# 控制台状态与交互

控制台是 HTTP 服务的客户端，展示与缓存不改变事实、图谱或检索评分。开发命令见 [frontend](../../frontend/README.md)，实现位于 [frontend/src](../../frontend/src/)。

## 凭据与查询隔离

凭据和查询错误只在页面内存保存，刷新后重新登录。每次登录/退出原子推进 epoch，同 `Key` 新登录也形成新周期；内部导航通过 `Router` 和 basename 保留应用，主动刷新仍清空内存。

请求捕获 `{key, epoch}`，在响应、正文读取和下载前复核；失败也先核对周期。旧 401 不退出新登录，过期请求以 `StaleSessionError(409)` 静默终止。登录周期变化取消并移除私有查询、清空错误和页面草稿，公共 health 保留。

取消查询防止迟到结果提交；支持 `AbortSignal` 的查询同时取消传输，但不撤回服务端已经收到的写入。隐私导出在提示和创建下载前再次检查周期，`finally` 释放 URL 与元素；已触发的下载不能追溯撤销。

启动仅尝试清理旧浏览器 `auth/query-error` 项，不恢复其中凭据。内存态不能消除登录期间的 XSS 风险，脚本授权仍由服务 CSP 约束。

## 页面、错误与草稿

`Layout` 保留 `Outlet`，全局错误条负责提示和重试，局部 `ErrorState` 始终说明当前区域失败。辅助查询或刷新失败不销毁无关编辑组件，已有数据保留并标记刷新失败；来源错误和成功空结果分开。

dirty 输入不被恢复响应覆盖。结论编辑行以 `Fact` ID 保持身份，连续分组仅控制展示；草稿限当前页面及登录周期，不跨路由、刷新或新登录恢复。验证见 [错误生命周期回归](../../frontend/tests/consoleErrors.test.cjs)和[工程索引](../../results/engineering/README.md#console-lifecycle)。

## 列表与一致分页

Facts、Timeline、Journal、Conversations 共用 `memoryPages`。服务在分页前组合类型、状态、搜索、分类、敏感范围和 `outcome_kind`，再统计与稳定排序。空间 counts 与匹配 `page.total` 不混用，分类候选不被当前搜索或页数缩减。

分页缓存身份包含账号、完整筛选和页大小；`next_offset`、提交版本及 `evaluated_at` 随页面链传递。后续页成对携带 `expected_revision/evaluated_at`；提交变化返回 409/`memory_revision_changed`。固定时刻统一过滤、行状态及事实统计，重载才取新时刻；不提供独立历史快照。

Infinite Query 是页面链唯一提交者。重载和写后刷新从新第一页重建已加载深度，全部成功后替换，任一后续页失败保留旧页和草稿。写后先取消所有受影响查询，再复核登录周期并失效，以覆盖无缓存首屏的 pending 去重问题。

普通下一页失败仅重试该页；版本或协议冲突停止追加并提供显式重载，不自动循环追赶外部写入。占位数据只允许同范围搜索，计数显示等待、分页禁用，不能冒充新查询的空结果。

Journal 在服务端分页前过滤四类结论，待解决卡片独立查询 `live` `open_question`；原始对话以 `Episode` ID 保存行与展开身份。SessionPicker 独立读取会话索引，新 ID 确认只改变选择，首次写入才产生服务记录；关闭操作绑定卡片 ID。

契约见 [HTTP 分页](../reference/http-api.md#记忆列表的筛选与一致分页)，验证见 [memoryPages](../../frontend/tests/memoryPages.test.cjs)。

## 事实、画像、体检与隐私

属性事实编辑三元组，四类结论编辑完整 `statement`；原样保存和元数据修改不复活旧事实。画像 `source_count` 只表示不同来源数，访问强化独立展示。

audit 在 `limit` 前稳定按处理优先级排序，并统计全部发现；`slot_overflow` 与 `clear_slot` 使用同一 `live` 非手写集合，`expect_count` 保护过期确认。体检不是完整语义或隐私审计，结果中的文本也不等同于来源原文。

Privacy 默认 compact，只导出非敏感结构化事实及派生图；with-originals 才请求完整私有导出。空间说明取 `agent_status.user`，不使用 `Key` 作为公开名称。单条擦除、会话收尾和整空间清空的范围不同。

未完成的来源交互、时间线、结论重复和单会话删除见[问题台账](../issues.md)。

## 展示偏好与主题

白名单偏好存入版本化 `localStorage`。页面筛选按 API 地址和凭据的 UTF-8 SHA-256 指纹隔离；原生 digest 不可用时使用固定 JS SHA-256，均失败才使用临时内存标识。异步激活与延迟写入核对 epoch，旧周期不能回写。

缓存版本不同即整体恢复默认并回写，不迁移旧字段；存储不可用仍可在内存操作。主题和图谱外观/受力参数为浏览器通用设置，敏感内容、`Key`、搜索、草稿和问答结果不写入偏好。

同步同源 `theme-init.js` 在首屏恢复 `dark`/`light`。界面固定中文，记忆正文和复制内容保留原文。减少动态或缺少 View Transition 时直接显示或使用简单过渡，主题不参与服务鉴权。

## 图谱与装饰

`GraphPage` → `ForceGraph` → Quartz 适配层，由 `D3` 模拟、Pixi 绘制和 `Tween.js` 邻接高亮组成。数据与模拟使用副本，弹簧按实体对去重，历史边和自环仍按实际关系展示。Pixi 使用受限 CSP 下的静态实现。

完整图决定模型和布局，`liveOnly` 只改变显示/命中；统计、详情与键盘列表使用同一可见集合。节点尺寸反映不同邻居数，不能解释为 `salience`。服务端限额后再过滤的缺口仍在问题台账。

首次进入先预计算和适配，再自然展开；返回复用按身份、稳定数据签名和参数隔离的有界内存视图。fit 保留设置/选择，reset 恢复默认；交互可接管动画，结束不追加适配。标签按宽度截短，悬停或选择显示全名，不触发布局跳变。

卸载停止模拟、RAF、监听器并释放 GPU，迟到初始化可取消；缓存不持有画布。来源、版本和 MIT 许可见 [Quartz 说明](../../frontend/vendor/quartz/README.md)。

登录脑图是独立 SVG，背景粒子是独立 Canvas，均不读取真实记忆或凭据。隐藏、减少动态和卸载时停止调度并清理资源，不影响业务关系图。
