# 隐私页导出说明验收

日期：2026-10-17。

## 变更

- 默认选项显式为精简导出，选择器直接显示“精简导出（默认）”，去掉未选择提示。
- 导出说明使用现有状态接口返回的空间名称；请求未返回时保留通用描述，避免将受保护模式的 API Key 当作空间名称显示。
- 精简范围将包含与不包含内容合为一段，以分号分隔；窄屏按可用宽度自然换行。含原文范围列出全部事实（含敏感事实）、图谱、关注点、原始对话、摘要与画像。
- 底部用两段说明服务器保存、访问控制及配置的模型服务处理范围。

## 验证

在 `frontend/` 执行：

```powershell
node node_modules/typescript/bin/tsc -b
node node_modules/vite/bin/vite.js build
```

类型检查和生产构建通过。
Edge 实际页面核对：初始显示精简选项、空间名与范围；切换含原文后说明同步更新，再切回默认。
后续按用户要求移除范围说明的手动换行及 `pre-line` 样式，改为分号连接的单段文字。
此次只检查展示和选择器交互，没有下载真实数据或执行清空。
