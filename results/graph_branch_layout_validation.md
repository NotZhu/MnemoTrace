# 图谱独立分支与标签避让验收

日期：2026-10-15。范围：控制台展示层；不修改后端、存储、事实内容、检索算法或 API，不新增依赖。

## 实现

- 独立连通组分别布局；星形/多层树按叶数分配扇区，有环组保留力导向布局，并做有限交叉优化。
- 按节点与名称包围盒尝试不同排列宽度，适应实际画布长宽比例。
- 浏览器 Canvas 测量实际字体宽度；八方向与两档间距避让节点、文字和连线。选中节点全名优先。
- 拖动只唤醒所属组，独立组包围盒相遇时推开；初始化和交叉修正采用 280ms 插值，减少动画偏好下停用 RAF。
- 普通关系保持直线，失效虚线和原始关系数据保留。小图标签保持可读，密集图中没有安全位置的标签通过 title/详情补充查看。
