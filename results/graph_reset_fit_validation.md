# 图谱重新布局与动画适配验收

日期：2026-10-15。范围：前端相机与显式重置生命周期，数据和 API 不变。

## 当前行为

用户确认两个按钮共用重新布局与自然展开流程，但参数处理不同：

- 适应画布：按当前设置重新布局、适配并播放展开，保留设置、筛选和选中实体，键盘 Home/0 同步采用此行为。
- 重置图谱：恢复默认设置、清除选择，再使用相同流程；筛选开关不变。
- 删除此前 `fitAfterReset`/结束时补 fit 的方案，避免动画结束后突然偏移。
- 新增 `src/vendor/quartz/motion.ts`：用真实 D3 记录 88% 收拢、alpha 0.35 至冷却的轨迹，先按最终位置适配一次，再按时间插值播放，结束不移动相机。
- 参数调节、拖动、尺寸或数据变化中断播放，从当前可见坐标继续；缩放和平移可以与播放并行，轨迹不覆盖相机。
- 减少动画模式立即显示静态结果；播放中切换为减少动画时直接显示已计算终点。
- 普通首次进入、切页返回仍保留现有实时 D3 展开与相机恢复规则；“仅当前”仍只控制显隐。

没有修改服务端数据、API 或引入新的第三方依赖；本次不涉及交叉优化或文字避让。
