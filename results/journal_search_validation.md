# 会话结论搜索验收（2026-10-12）

## 原因与修复

- 原页面将输入值直接作为请求词；每次查询键变化都会进入初始加载，并整页替换为 Spinner。
- 浏览器填入新搜索词后，文本仍在但输入框失焦，复现结论为 FAIL。
- 工具栏固定挂载，加载/错误只影响结果区域；停止输入 250ms 后请求，组词期间暂停请求。
- 查询刷新期间保留同空间、同记录类型的上一页结果；其他调用默认不启用。空间变化时不使用旧数据。
- 搜索框垂直内边距改为 12px、圆角 16px；保留按钮布局及筛选语义。

## 验证

- `npm run test:search`：3 项通过，真实 QueryObserver 检查保留结果、空间隔离、类型及默认行为。
- `npm run build`：TypeScript 和 Vite 构建通过。
- 浏览器填入新词、连续输入六个中文字符后，内容完整且焦点保留，复查结论为 PASS。
- 此记录不包含用户真实搜索词或记忆内容，不涉及新的算法 benchmark。

## 筛选控件细节

- 原复选框替换为“小开关配文字”，文案为“包含历史版本”，保持原 `showSuperseded` 查询逻辑。
- 分类显示名称统一为“全部、决定、发现、经验、待解决”，内部 predicate 保留原值。
- 浏览器确认鼠标点击和空格键可双向切换，页面持续挂载，构建通过。
