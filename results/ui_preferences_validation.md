# 控制台界面偏好长期保存验收

日期：2026-10-15。只调整前端展示偏好和普通开关样式，不修改服务端记忆数据。

## 范围与行为

- 新增 `frontend/src/store/preferences.ts`，用现有 Zustand/persist 和 localStorage，键为 `mnemotrace.preferences`，版本 1，无新增包依赖。
- 浏览器通用：图谱节点大小、线宽、文字显现程度、关系名称开关、斥力、中心力、连线距离/拉力。
- 身份隔离：图谱仅当前/隐藏敏感、事实包含历史/隐藏敏感、会话结论包含历史版本、问答片段数/隐藏敏感事实。
- 身份由 API 地址与登录凭据 SHA-256 派生，与查询缓存的隔离边界一致。偏好不保存凭据原文；同一后端 user 换 key 后偏好不会自动合并。
- 开关与问答选项立即保存。图谱滑条即时渲染，写入合并 150ms，离开图谱与 pagehide 补存；重置写入默认值。
- 搜索、输入草稿、问答结果、历史日期、删除确认、写入范围、敏感标记和节点位置不进入长期偏好。
- 类型、字段、范围、缺失字段和版本校验；损坏缓存使用默认值，存储异常不阻断操作。没有 Web Crypto 时，筛选在不落盘的临时空间中使用。
