# 图谱切页返回状态验收

日期：2026-10-15。范围：前端图谱浏览生命周期，不更改实体、关系、查询 API 或服务端记忆。

## 复现与修改

用户关闭“仅当前”后再切页返回，数据数量保持一致，但节点位置发生明显变化。
原模型在数据更新时可继承坐标，组件重新创建时从 D3 初始种子开始，因此布局起点不同。

新增 `quartzViewport.test.cjs` 中“加入历史关系后切页再进入”场景：从当前图添加历史节点/边，推进真实 D3，
执行缩放和平移，销毁后重新创建控制器，比较节点和相机。修复前该测试失败于节点坐标不一致。

新增 `vendor/quartz/view.ts` 内存缓存，按登录身份、稳定图签名、受力配置隔离，最多 24 份。
卸载/换数据前保存；相同图返回使用缓存坐标，不重新静态求解布局。数组换序/相同数据响应不触发重新布局。
新图保留原初始化与动画；重置忽略缓存。无持久化 API，无 localStorage/sessionStorage 读写。

用户明确要与首次进入相同的动画后，移除此前 420ms 绘制插值，首次和返回统一调用 `startEntrance`。
缓存坐标收拢到 88%，速度清零，以 alpha 0.35 重启真实 D3 受力运动，节点会自然展开并稳定，相机不变。
入场期间保存收拢前基准；中途离开仍保存基准，动画结束/主动拖动/调参/改尺寸后改为保存实际位置。减少动画偏好下直接恢复。
回归先改为要求真实节点收拢及模拟重启，修改前失败于“从缓存布局按首次入场比例收拢”，修改后通过。

## 生命周期边界

缓存只在当前运行内有效，刷新后重新生成；显示/筛选偏好仍按之前规则长期保存。
返回时以缓存位置为起点，并与首次进入一样自然受力展开，因此动画结束后的节点位置可有调整。
首次或返回入场未结束就离开时，快照保存收拢前基准；交互/运动结束后保存实际位置。新数据或受力参数不同不复用旧快照。
