# 图谱自然分布与交互稳定验收

日期：2026-10-15。范围：前端展示算法及交互，不修改后端、实体身份、关系内容、检索逻辑或 API，不新增依赖。

## 调整

- 独立组改为整体受力分布，移除按行对齐；小图比较有限个稳定初始方向，避免偶然排成竖列。保留文字包围盒分离，不通过隐藏关系消除交叉。
- 根据实体 ID 派生稳定方向和有界扇区/半径变化，减少水平短线排队与规则轮辐；重复运行和输入顺序变化保持稳定。
- 结合拟合后的文字字号有限次调整组间空间。单组不重复计算组间排列。
- 优先验证并沿用上次标签位置，被节点、连线或其他文字遮挡后才换方向；小图加入第三档距离候选。
- 弹簧目标长度小幅变化保持确定；组中心跟随当前重心，整体移动后不再回拉到旧中心。局部唤醒、组间避让和减少动画偏好保留。
