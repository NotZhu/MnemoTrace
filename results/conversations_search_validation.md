# 原始对话页搜索与表单验收（2026-10-15）

## 问题与修复

会话列表把每次输入直接传给 `useSessions`；查询 key 改变后没有上一页占位数据，列表被加载状态替换。
修复后复用 `useDebouncedSearch`：停顿 500ms 再提交搜索词，中文组词期间不提交拼音，清空立即恢复。
`useSessions` 提供可选的 `keepPreviousData`，仅允许同一记忆空间沿用上一页会话，返回新结果后替换。
其他未启用该选项的调用保持原加载行为。

表单标题为“添加记忆”，标签使用“会话 ID”和“当前空间”。记忆内容框初始一行；会话 ID 输入时保留本次编辑开始时的文字底影，失焦后结束本次对照，底影不提交到后端。
