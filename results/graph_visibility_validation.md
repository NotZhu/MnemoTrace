# 图谱“仅当前”显隐验收

日期：2026-10-15。仅修改前端展示和查询使用方式，不改变服务端图谱、事实或 API 定义。

## 修改

- GraphPage 在当前搜索、敏感过滤和 limit 120 范围内统一请求 `live_only: false`，将同一完整数据传给 ForceGraph。
- `src/lib/graphVisibility.ts` 统一派生可见关系及其端点。统计、详情和无障碍节点列表使用该结果；隐藏独有节点后清除选择，重新显示时不恢复旧选择。
- Quartz 控制器新增 `setLiveOnly`，只更新节点/文字/连线显隐及高亮，不重建模型、不重新计算受力、不 tick、不 reheat、不 fit。
- 隐藏节点不参与命中，隐藏边不参与邻居高亮。只剩历史关系时展示空态，但保持同一画布和完整模型。
- 物理弹簧、圆点半径、初始适配和视图缓存均以完整数据为依据。两种状态共享节点坐标和相机；隐藏关系仍参与完整布局。
- 首次进入及切页返回共用的自然受力动画保留。动画尚未冷却时仍会自然运动，开关不会额外重启它。
- 搜索和敏感过滤变化仍会获取不同图数据，允许按原流程重新布局；本次稳定显隐仅针对“仅当前”。计数仅针对本次完整查询返回的范围。
